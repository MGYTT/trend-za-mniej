# Testowa wtyczka Chrome 0.5.0

- Publiczna strona: /wtyczka-chrome
- CTA: /kody-rabatowe
- Paczka ZIP: /downloads/trendzamniej-chrome-0.5.0.zip
- W pliku ZIP znajduje się katalog trendzamniej-chrome-0.5.0 zawierający manifest.json i pliki rozszerzenia.

W Chrome przejdź na chrome://extensions → włącz Tryb dewelopera → Załaduj rozpakowane → wybierz folder.
To nie jest jeszcze opublikowana instalacja z Chrome Web Store.

Po otwarciu asystenta na stronie sklepu użytkownik może skopiować kupon, wypróbować go samodzielnie
i oznaczyć wynik dla siebie. Wynik pozostaje tymczasowy, wyłącznie w panelu i bez zapisu na serwerze.
Kody kampanii nie są przedstawiane jako kupony do koszyka. Nie ma automatycznego testowania.
